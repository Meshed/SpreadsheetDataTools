## Risk Coverage

Based on Story 2.4 implementation complexity:

- **SEC-001: Field data exposure**: Covered by sample data tests (2.4-UNIT-010, 2.4-UNIT-011)
- **PERF-001: Large field lists**: Covered by bulk operations (2.4-UNIT-013, 2.4-UNIT-014)
- **REL-001: State persistence**: Covered by navigation tests (2.4-INT-001, 2.4-INT-002)
- **REQ-001: Missing field validation**: Covered by validation tests (2.4-UNIT-015, 2.4-INT-007)

## Test Implementation Guidelines

### Unit Test Focus Areas
- Field extraction algorithms from ProcessedData and FileData
- Selection state management with Set operations
- Default selection business logic
- Validation rules and error handling
- Sample data processing and formatting

### Integration Test Focus Areas  
- Wizard step transitions and state preservation
- Component interaction with ExtractorModel state
- Message routing between Update.elm handlers
- Cross-step data flow from preview to select fields

### E2E Test Focus Areas
- Complete user journey through field selection
- Visual feedback and accessibility compliance
- Critical path validation for data extractor workflow
- User interaction patterns with bulk operations
