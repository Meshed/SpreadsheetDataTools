# Story 2.2: Configure Matching Criteria

## Status
Done

## Story
**As a** user,  
**I want** to select multiple fields for matching between spreadsheets,  
**so that** I can create more precise matches using combinations of columns.

## Acceptance Criteria
1. Wizard step 2 displays column headers from both uploaded spreadsheets
2. Multi-select interface allows selecting multiple fields from master spreadsheet for matching
3. Multi-select interface allows selecting multiple fields from data spreadsheet for matching
4. Selected fields display in order of selection with clear numbering (1st, 2nd, 3rd...)
5. Matching logic explanation: "Columns match by selection order - 1st selected master column matches 1st selected data column, etc."
6. Visual example shows matching pairs: "Master Col A (1st) ↔ Data Col C (1st), Master Col D (2nd) ↔ Data Col F (2nd)"
7. Reorder functionality allows changing selection order via drag-and-drop or up/down buttons
8. Remove individual selections without starting over
9. Must select at least one field from each spreadsheet to proceed
10. Fuzzy matching option applies to all selected text fields with explanation
11. Preview shows sample data from all selected fields for validation
12. Progress indicator shows step 2 of 5 as active

## User Stories & UX Workflows for E2E Testing

### AC1: Column Headers Display
**User Story:** As a user who has uploaded two spreadsheets, when I reach step 2 of the wizard, I want to see all column headers from both files clearly displayed so I can understand what data is available for matching.

**UX Workflow:**
1. **Given:** User has completed step 1 with master.xlsx (columns: Name, ID, Email) and data.xlsx (columns: Full Name, Employee ID, Department, Salary)
2. **When:** User clicks "Next" from upload step
3. **Then:** Page displays "Configure Matching Criteria" heading
4. **And:** Left panel shows "Master Spreadsheet Columns" with: Name, ID, Email
5. **And:** Right panel shows "Data Spreadsheet Columns" with: Full Name, Employee ID, Department, Salary
6. **And:** Column headers are clickable/selectable elements
7. **And:** Progress bar shows step 2 of 5 as active

### AC2: Master Spreadsheet Multi-Select
**User Story:** As a user configuring matching criteria, I want to select multiple columns from my master spreadsheet so I can create more precise matches using multiple data points.

**UX Workflow:**
1. **Given:** Column headers are displayed from master spreadsheet
2. **When:** User clicks "Name" column
3. **Then:** "Name" becomes visually selected (highlighted/checked)
4. **And:** Selection number "1st" appears on the Name column
5. **When:** User clicks "ID" column
6. **Then:** "ID" becomes selected with number "2nd"
7. **And:** Both "Name" and "ID" remain selected simultaneously
8. **When:** User clicks "Email" column
9. **Then:** "Email" becomes selected with number "3rd"
10. **And:** All three columns show as selected with proper numbering

### AC3: Data Spreadsheet Multi-Select
**User Story:** As a user, I want to select multiple columns from my data spreadsheet that correspond to my master selections so the system knows which fields to match against.

**UX Workflow:**
1. **Given:** Master columns "Name" (1st) and "ID" (2nd) are selected
2. **When:** User clicks "Full Name" from data columns
3. **Then:** "Full Name" becomes selected with "1st" indicator
4. **When:** User clicks "Employee ID" from data columns  
5. **Then:** "Employee ID" becomes selected with "2nd" indicator
6. **And:** Both data columns remain selected with proper numbering
7. **And:** Visual connection shows pairing between master and data selections

### AC4: Selection Order Display
**User Story:** As a user making multiple selections, I want to clearly see the order of my column selections so I understand how the matching will work.

**UX Workflow:**
1. **Given:** User selects columns in this order: Master "Name", Master "ID", Data "Full Name", Data "Employee ID"
2. **Then:** Master side shows: "Name (1st)", "ID (2nd)"
3. **And:** Data side shows: "Full Name (1st)", "Employee ID (2nd)" 
4. **And:** Numbers are prominently displayed (badges, colors, or clear text)
5. **And:** Selection order is visually consistent across both sides
6. **When:** User adds Master "Email" (3rd)
7. **Then:** Email shows "3rd" indicator
8. **And:** Previous selections maintain their numbering

### AC5: Matching Logic Explanation
**User Story:** As a user new to the matching concept, I want a clear explanation of how column matching works so I can make informed selections.

**UX Workflow:**
1. **Given:** User is on the configure step
2. **Then:** Prominent explanation text appears: "Columns match by selection order - 1st selected master column matches 1st selected data column, etc."
3. **And:** Explanation is positioned prominently (top of interface or highlighted box)
4. **And:** Text uses clear, non-technical language
5. **And:** Explanation remains visible while user makes selections
6. **When:** User makes selections
7. **Then:** Explanation reinforces the concept with live updates

### AC6: Visual Matching Pairs Example
**User Story:** As a user, I want to see exactly how my selected columns will be paired for matching so I can verify my configuration is correct.

**UX Workflow:**
1. **Given:** Master columns "Name" (1st), "ID" (2nd) and Data columns "Full Name" (1st), "Employee ID" (2nd) are selected
2. **Then:** Visual pairing display shows:
   - "Name (1st) ↔ Full Name (1st)"
   - "ID (2nd) ↔ Employee ID (2nd)"
3. **And:** Arrows or connecting lines clearly show the relationships
4. **And:** Pairing display updates automatically when selections change
5. **When:** User adds Master "Email" (3rd) but no corresponding data column
6. **Then:** Warning appears: "Data spreadsheet needs 3rd column selection"
7. **When:** User adds Data "Department" (3rd)
8. **Then:** Pairing shows: "Email (3rd) ↔ Department (3rd)"

### AC7: Reorder Functionality
**User Story:** As a user who realizes I selected columns in the wrong order, I want to reorder my selections without starting over so I can quickly fix my matching configuration.

**UX Workflow - Up/Down Buttons:**
1. **Given:** Selected columns: Master "Name" (1st), "ID" (2nd), "Email" (3rd)
2. **When:** User clicks "up" button next to "Email" (3rd)
3. **Then:** "Email" moves to 2nd position, "ID" moves to 3rd
4. **And:** New order: "Name" (1st), "Email" (2nd), "ID" (3rd)
5. **And:** Matching pairs display updates automatically
6. **And:** "Up" button is disabled for 1st item, "Down" disabled for last item

**UX Workflow - Drag and Drop:**
1. **Given:** Same selected columns as above
2. **When:** User drags "Email" (3rd) and drops it between "Name" and "ID"
3. **Then:** Visual feedback shows drop zones during drag
4. **And:** On drop: "Name" (1st), "Email" (2nd), "ID" (3rd)
5. **And:** Drag feedback includes ghost image or visual indicators

### AC8: Individual Selection Removal
**User Story:** As a user who made an incorrect selection, I want to remove individual columns without clearing all my selections so I can efficiently correct my configuration.

**UX Workflow:**
1. **Given:** Selected Master columns: "Name" (1st), "ID" (2nd), "Email" (3rd)
2. **When:** User clicks remove/X button on "ID" (2nd)
3. **Then:** "ID" becomes unselected and disappears from selected list
4. **And:** "Email" automatically renumbers from 3rd to 2nd
5. **And:** Matching pairs display updates to show: "Name" (1st) ↔ ?, "Email" (2nd) ↔ ?
6. **And:** Other selections remain intact
7. **When:** User removes data column "Employee ID" (2nd)
8. **Then:** Only "Name" ↔ "Full Name" pairing remains

### AC9: Minimum Selection Validation
**User Story:** As a user, I want clear feedback when I haven't made sufficient selections so I know what's needed to proceed to the next step.

**UX Workflow:**
1. **Given:** User has selected no columns
2. **Then:** "Next" button is disabled
3. **And:** Validation message: "Select at least one column from each spreadsheet"
4. **When:** User selects Master "Name" only
5. **Then:** Validation message: "Select at least one column from data spreadsheet"
6. **And:** "Next" button remains disabled
7. **When:** User selects Data "Full Name"
8. **Then:** Validation message disappears
9. **And:** "Next" button becomes enabled
10. **When:** User removes all selections
11. **Then:** Validation error reappears immediately

### AC10: Fuzzy Matching Option
**User Story:** As a user whose data might have slight variations (like "John Smith" vs "John S."), I want a fuzzy matching option so I can catch more potential matches.

**UX Workflow:**
1. **Given:** User has made column selections
2. **Then:** Fuzzy matching checkbox appears with label: "Enable fuzzy matching"
3. **And:** Help text explains: "Matches similar text (e.g., 'John' matches 'John Smith')"
4. **When:** User checks the fuzzy matching option
5. **Then:** Checkbox becomes checked/active
6. **And:** All selected text fields will use fuzzy matching logic
7. **And:** Visual indicator shows fuzzy matching is active
8. **When:** User unchecks the option
9. **Then:** Matching reverts to exact matching only

### AC11: Sample Data Preview
**User Story:** As a user, I want to see actual sample data from my selected columns so I can verify I've chosen the right fields and the matching will work correctly.

**UX Workflow:**
1. **Given:** User selects Master "Name", "ID" and Data "Full Name", "Employee ID"
2. **Then:** Preview table appears showing:
   - Master data: 3 rows of Name and ID values
   - Data data: 3 rows of Full Name and Employee ID values  
3. **And:** Preview updates automatically when selections change
4. **When:** User adds Master "Email"
5. **Then:** Preview adds Email column with 3 sample values
6. **When:** User removes Data "Employee ID"
7. **Then:** Preview removes Employee ID column
8. **And:** Preview handles empty columns gracefully (shows "No data" or blank)

### AC12: Progress Indicator
**User Story:** As a user progressing through the wizard, I want to see that I'm on step 2 of 5 so I understand my progress and how many steps remain.

**UX Workflow:**
1. **Given:** User navigates from step 1 to step 2
2. **Then:** Progress bar shows step 2 as active/current
3. **And:** Steps 1-2 appear completed/passed
4. **And:** Steps 3-5 appear upcoming/inactive
5. **And:** Progress indicator shows "Step 2 of 5" or "2/5"
6. **And:** Current step is clearly distinguished (color, highlight, or bold)
7. **When:** User clicks "Next" to step 3
8. **Then:** Step 2 becomes completed, step 3 becomes active

### UI Component Patterns
[Source: architecture/frontend-architecture.md, architecture/components.md]

**Multi-Select Interface Pattern:**
```elm
-- Column selection component
columnSelector : String -> List String -> List String -> (String -> msg) -> Html msg
columnSelector label availableColumns selectedColumns onToggle =
    div [ class "column-selector" ]
        [ h3 [ class "column-selector__title" ] [ text label ]
        , div [ class "column-selector__list" ]
            (List.map (columnOption onToggle selectedColumns) availableColumns)
        ]

-- Individual column option with selection state
columnOption : (String -> msg) -> List String -> String -> Html msg
columnOption onToggle selected column =
    let
        isSelected = List.member column selected
        selectionIndex = getSelectionIndex column selected
    in
    button
        [ class (columnOptionClass isSelected)
        , onClick (onToggle column)
        ]
        [ text column
        , selectionNumberBadge selectionIndex
        ]
```

**Drag-and-Drop Pattern:**

-- Reorderable list item

### Matching Engine Integration
[Source: architecture/components.md]

**Matching Engine Location:**
- Pure functions in `src/Shared/Processing/Matching/Engine.elm`
- Purpose: Process MatchConfig with FileData to generate matched results
- Current Implementation: Available from previous stories

**MatchConfig Creation:**
```elm
-- Build MatchConfig from user selections
buildMatchConfig : List String -> List String -> Bool -> MatchConfig
buildMatchConfig masterCols dataCols fuzzyEnabled =
    { masterColumns = masterCols
    , dataColumns = dataCols
    , fuzzyEnabled = fuzzyEnabled
    , threshold = 0.8  -- Default fuzzy threshold
    , caseSensitive = False  -- Default case insensitive
    }

-- Validation for MatchConfig requirements
validateMatchConfig : MatchConfig -> Result String MatchConfig
validateMatchConfig config =
    if List.isEmpty config.masterColumns then
        Err "Must select at least one master column"
    else if List.isEmpty config.dataColumns then
        Err "Must select at least one data column"
    else if List.length config.masterColumns /= List.length config.dataColumns then
        Err "Must select same number of columns from each spreadsheet"
    else
        Ok config
```
