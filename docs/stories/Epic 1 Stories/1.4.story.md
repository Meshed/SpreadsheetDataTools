### Coding Standards Requirements
[Source: architecture/coding-standards.md#css-standards]

**Critical CSS Rules:**
- **No Inline Styles:** All styling must be in separate CSS files using BEM methodology - zero style attributes
- **BEM Methodology:** Use Block__Element--Modifier naming convention consistently
- **CSS Variables:** All colors, spacing, and design tokens must use CSS custom properties
- **Component Organization:** Each component gets its own CSS file
- **Pure CSS:** Custom CSS with no external framework dependencies

**BEM Naming Examples:**
```css
/* Block */
.tool-card { }

/* Element */
.tool-card__title { }
.tool-card__description { }
.tool-card__button { }

/* Modifier */
.tool-card--primary { }
.tool-card--disabled { }
.tool-card__button--large { }
```
